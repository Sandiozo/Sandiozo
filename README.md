### Hi, I'm Sandis

I build **[RimDeck](https://github.com/Sandiozo/RimDeck)**, a fast, free and open-source mod manager for RimWorld on Windows, macOS and Linux: auto-sort that explains every move, live problem checks, texture conflicts, a research tree, mod settings without starting the game, and a Continue button that drops you straight back into your colony.
